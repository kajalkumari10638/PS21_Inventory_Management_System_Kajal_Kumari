# Inventory Management System

**Project statement PS 21** · Python console application

Add, view, update, delete, and search inventory items. The program calculates the total stock value and reports items with a quantity below five.

## Run

From the repository root, run this command with Python 3.

```sh
python codebase/inventory.py
```

Each item has an ID, name, quantity, and price. IDs start at 1101. Inventory is stored in memory and starts empty each time the application runs. The project uses the Python standard library.
